# Python - Everything is Object

This project explores how Python handles objects, references, mutability, and memory management.

## Files

- **0-answer.txt**: Function to print type of an object
- **1-answer.txt**: Function to get variable identifier
- **2-answer.txt**: Do a and b point to the same object (a=89, b=100)
- **3-answer.txt**: Do a and b point to the same object (a=89, b=89)
- **4-answer.txt**: Do a and b point to the same object (b=a)
- **5-answer.txt**: Do a and b point to the same object (b=a+1)
- **6-answer.txt**: s1 == s2 with alias
- **7-answer.txt**: s1 is s2 with alias
- **8-answer.txt**: s1 == s2 with same string
- **9-answer.txt**: s1 is s2 with same string
- **10-answer.txt**: l1 == l2 with same list content
- **11-answer.txt**: l1 is l2 with same list content
- **12-answer.txt**: l1 == l2 with alias
- **13-answer.txt**: l1 is l2 with alias
- **14-answer.txt**: List append behavior
- **15-answer.txt**: List add behavior
- **16-answer.txt**: Integer incrementation in function
- **17-answer.txt**: List incrementation in function
- **18-answer.txt**: List assignation in function
- **19-copy_list.py**: Function that returns a copy of a list
- **20-answer.txt**: Is () a tuple
- **21-answer.txt**: Is (1, 2) a tuple
- **22-answer.txt**: Is (1) a tuple
- **23-answer.txt**: Is (1,) a tuple
- **24-answer.txt**: a is b with (1)
- **25-answer.txt**: a is b with (1, 2)
- **26-answer.txt**: a is b with ()
- **27-answer.txt**: Does id change with a = a + [5]
- **28-answer.txt**: Does id change with a += [4]
