# JavaScript - Warm up

Basic JavaScript scripting project covering variables, data types, control
flow, functions, arrays/objects, and modules using Node.js.

## Requirements

- Interpreted on Ubuntu 20.04 LTS with Node.js 14.x
- All files start with `#!/usr/bin/node` and are executable
- Code is semistandard compliant (`semistandard` linter passes with no errors)
- No use of `var` — only `const` / `let`

## Tasks

| File | Description |
| --- | --- |
| `0-javascript_is_amazing.js` | Prints a constant string |
| `1-multi_languages.js` | Prints 3 fixed lines |
| `2-arguments.js` | Reports number of CLI arguments |
| `3-value_argument.js` | Prints the first CLI argument |
| `4-concat.js` | Builds a sentence from two arguments |
| `5-to_integer.js` | Converts first argument to an integer |
| `6-multi_languages_loop.js` | Same as task 1, using an array + loop |
| `7-multi_c.js` | Prints "C is fun" N times |
| `8-square.js` | Prints a square of X characters |
| `9-add.js` | Adds two integers via an `add` function |
| `10-factorial.js` | Computes factorial recursively |
| `11-second_biggest.js` | Finds the second biggest of the arguments |
| `12-object.js` | Mutates an object property |
| `13-add.js` | Exports an `add` function via `module.exports` |
