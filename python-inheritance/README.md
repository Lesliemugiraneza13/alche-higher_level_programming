# Python - Inheritance

This project covers inheritance in Python, including single and multiple inheritance, superclasses, subclasses, and built-in functions like isinstance, issubclass, type and super.

## Files

- **0-lookup.py**: Returns list of available attributes and methods of an object
- **1-my_list.py**: Class MyList that inherits from list with print_sorted method
- **2-is_same_class.py**: Function that checks if object is exactly an instance of specified class
- **3-is_kind_of_class.py**: Function that checks if object is instance of or inherits from a class
- **4-inherits_from.py**: Function that checks if object is instance of a class that inherited from specified class
- **5-base_geometry.py**: Empty class BaseGeometry
- **6-base_geometry.py**: BaseGeometry class with area method
- **7-base_geometry.py**: BaseGeometry class with area and integer_validator methods
- **8-rectangle.py**: Rectangle class that inherits from BaseGeometry
- **9-rectangle.py**: Full Rectangle class with area and string representation
- **10-square.py**: Square class that inherits from Rectangle
- **11-square.py**: Square class with string representation
